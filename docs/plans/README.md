# docs/plans — kế hoạch đang thực thi

Quy tắc (xem `docs/DECISIONS.md` 04/10/2026):
- Chỉ tạo kế hoạch khi việc **> 1 ngày** hoặc **nhiều bước phụ thuộc**.
- Thiết kế kiến trúc → cập nhật `docs/architecture/`, không tạo file ở đây.
- Xong việc → **xóa file kế hoạch** (git giữ lịch sử). Thư mục này thường trống.
- Việc nhỏ / sửa lỗi: commit message + test, không cần kế hoạch.
